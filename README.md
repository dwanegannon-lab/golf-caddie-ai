# Golf Caddie AI

Golf Caddie AI is an Android app concept for golfers that combines GPS weather awareness, club tracking, score keeping, and AI-powered club recommendations.

## Features
- Login with Google or a golfer name
- Personalized greeting and local weather awareness
- Nearby course discovery using GPS location
- Club bag management with baseline distances and putter tracking
- Round setup for 18 holes, Front 9, or Back 9
- Hole-by-hole map and shot tracking with markers, club selection, and wind data
- AI guidance for club selection based on average shot distance
- Scorecard with multi-player support

## Tech stack
- Kotlin
- Jetpack Compose
- Material 3
- Android architecture components
- Google Play services location

## Getting started
1. Open the project in Android Studio.
2. Let Gradle sync the project dependencies.
3. Run the app on an emulator or Android device.

## Notes
This repository includes the Android app scaffold and user interface flows for the requested experience. You can extend the app with live weather APIs, Google Sign-In configuration, and actual course/map data in a production build.
